# صلواتي

تطبيق صلاة أندرويد: مواقيت الصلاة، أذان، قبلة، أذكار وأدعية. يعمل بدون إنترنت.

## التثبيت

نزّل الملف وفك ضغطه:

**https://github.com/markosbin4u/Horiszon/releases/latest/download/salawati.apk**

افتحه على الهاتف. إن رفض أندرويد التثبيت، اسمح بـ «تثبيت من مصادر غير معروفة» لهذا الملف.
التطبيق موقّع بمفتاح التطوير، وهذا كافٍ للتثبيت الشخصي والمشاركة، لكنه لا يكفي للنشر في Google Play.

## ما فيه

| الشاشة | ما تفعله |
| --- | --- |
| المواقيت | الفجر، الشروق، الظهر، العصر، المغرب، العشاء، مع عدّاد تنازلي للصلاة القادمة |
| القبلة | بوصلة حيّة باستخدام حسّاس الهاتف وموقعك، مع المسافة إلى الكعبة |
| الأذكار | أذكار الصباح والمساء والنوم وبعد الصلاة، مع عدد التكرار |
| الأدعية | أدعية مأثورة مع البحث ومناسبتها ومصدرها |
| الإعدادات | الموقع (GPS أو مدينة)، طريقة الحساب، مذهب العصر، الأذان، الوضع الليلي |

## طريقة الحساب

الحساب فلكي: ميل الشمس ومعادلة الزمن، ثم زوايا الغروب لكل وقت. الطريقة الافتراضية
**رابطة العالم الإسلامي** (الفجر 18°، العشاء 17°)، ويمكن اختيار أم القرى أو الهيئة
المصرية أو كراتشي أو وزارة الشؤون الدينية الجزائرية.

القيم مُختبَرة مقابل تنفيذ مستقل في `test/prayer_times_test.dart`: لباتنة يوم 26 نوفمبر
الفجر 05:52 والظهر 12:23 والمغرب 17:23.

## التقنيات

Flutter / Dart. لا خدمة خلفية ولا مجموعة بيانات أونلاين: كل الحساب على الهاتف.
الخط **Amiri** برخصة SIL OFL 1.1 (`fonts/AMIRI-LICENSE.txt`).
المقطع الصوتي للأذان: `assets/adhan.mp3` (أذان المدينة المنورة).

## البناء

```sh
cd salawati
flutter pub get
flutter test
flutter build apk --release
```

أو ادفع تعديلاً على `salawati/**` ويعمل GitHub Actions وحده.
